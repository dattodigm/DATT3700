# 硬件接线映射表 (Hardware Wiring Guide)

根据现有固件代码，以下是各模块的 ESP32 引脚分配。在进行底层重构前，请确保物理接线与此表严格对应。

## 1. Sylvie 节点 (2x DC马达, 2x RGB LED)

此节点需要使用 L298N 或类似的双 H 桥电机驱动模块连接马达，LED 假设为共阴极/共阳极普通 RGB。

| 组件 | 功能 | ESP32 引脚 | 备注说明 |
| --- | --- | --- | --- |
| **马达 A** | 正向/反向控制 (A) | GPIO 25 | 需连接至 L298N IN1 |
|  | 正向/反向控制 (B) | GPIO 26 | 需连接至 L298N IN2 |
| **LED 1** | 红色 (R) | GPIO 2 | 需串联限流电阻 |
|  | 绿色 (G) | GPIO 4 | 需串联限流电阻 |
|  | 蓝色 (B) | GPIO 5 | 需串联限流电阻 |
| **马达 B** | 正向/反向控制 (A) | GPIO 18 | 需连接至 L298N IN3 |
|  | 正向/反向控制 (B) | GPIO 19 | 需连接至 L298N IN4 |
| **LED 2** | 红色 (R) | GPIO 12 | 需串联限流电阻 |
|  | 绿色 (G) | GPIO 13 | 需串联限流电阻 |
|  | 蓝色 (B) | GPIO 14 | 需串联限流电阻 |

## 2. 云台追踪节点 (8x Servo)

此节点直接驱动 8 个舵机，需要外部独立 5V 电源供电，切勿直接通过 ESP32 的 5V 引脚取电，否则会因电流过大导致单片机重启或烧毁。必须共地 (GND)。

| 云台组号 | 轴向 | ESP32 引脚 | 备注说明 |
| --- | --- | --- | --- |
| **组 1** | X 轴 (水平) | GPIO 18 | 对应 `servosX[0]` |
|  | Y 轴 (垂直) | GPIO 19 | 对应 `servosY[0]` |
| **组 2** | X 轴 (水平) | GPIO 21 | 对应 `servosX[1]` |
|  | Y 轴 (垂直) | GPIO 22 | 对应 `servosY[1]` |
| **组 3** | X 轴 (水平) | GPIO 23 | 对应 `servosX[2]` |
|  | Y 轴 (垂直) | GPIO 25 | 对应 `servosY[2]` |
| **组 4** | X 轴 (水平) | GPIO 26 | 对应 `servosX[3]` |
|  | Y 轴 (垂直) | GPIO 27 | 对应 `servosY[3]` |

## 3. Sue 节点 (1x Servo, 2x 单色 LED)

控制单朵花的开合及状态指示灯。

| 组件 | 功能 | ESP32 引脚 | 备注说明 |
| --- | --- | --- | --- |
| **Servo** | 开合控制 | GPIO 18 | 闭合: 60°, 张开: 120° |
| **LED 1** | 红色指示灯 (危险) | GPIO 22 |  |
| **LED 2** | 绿色指示灯 (放松) | GPIO 23 |  |
